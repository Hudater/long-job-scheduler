# long-job-scheduler

A job scheduler I'm building one chapter at a time while working through boot.dev's Learn Go course. The full requirement list lives in [REQUIREMENT.md](./REQUIREMENT.md), scratch notes in [NOTES.md](./NOTES.md).

## Run

One file until chapter 12:

```
go run main.go
```

After the package split:

```
go run ./cmd/scheduler
```
